
# Money - Expense Tracker

Այս հավելվածը նախատեսված է ծախսերը գրանցելու,
կառավարելու և ընդհանուր գումարը հաշվելու համար։

## Հնարավորություններ

- Ծախսերի ավելացում
- Ծախսերի ցուցադրում
- Կատեգորիաների ընտրություն
- Ծախսերի ֆիլտրում
- Ընդհանուր գումարի հաշվարկ
- Ծախսերի ջնջում
- Ջնջված ծախսերի վերադարձնում
- Ծախսի գումարի փոփոխում

## 1. Որտե՞ղ եմ պահում ծախսերի ցուցակը և ինչու

Ծախսերի ցուցակը պահում եմ HomeScreen-ի
_StatefulWidget_-ի ներսում՝ որպես List<Expense>։

Օգտագործում եմ StatefulWidget, որովհետև ծախսերի
ցուցակը փոփոխվում է։ Երբ ավելացնում, ջնջում կամ
փոփոխում եմ ծախսը, օգտագործում եմ setState(),
որպեսզի էկրանը թարմացվի։

## 2. Ինչպե՞ս եմ հաշվում ընդհանուր գումարը

Ընդհանուր գումարը հաշվում եմ fold() մեթոդի միջոցով։

Այն գումարում է բոլոր ծախսերի amount արժեքները։

Առանձին փոփոխականում գումարը չեմ պահում, որովհետև
ծախսերի ավելացման, ջնջման կամ փոփոխման ժամանակ
այն կարող է սխալ արժեք ունենալ։

Այդ պատճառով ընդհանուր գումարը ամեն անգամ
հաշվարկվում է ցուցակի տվյալների հիման վրա։

## 3. Ինչո՞ւ է Dismissible-ի Key-ը expense.id,
ոչ թե index

Օգտագործում եմ ValueKey(expense.id), որովհետև
յուրաքանչյուր ծախս ունի իր յուրահատուկ ID-ն։

Երբ ցուցակից որևէ տարր ջնջվում է, մյուս տարրերի
index-ները փոխվում են։

Եթե օգտագործեմ index-ը որպես Key, Flutter-ը
կարող է սխալ նույնականացնել ցուցակի տարրերը։

Իսկ expense.id-ն մնում է նույնը նույնիսկ այն
ժամանակ, երբ ցուցակի հերթականությունը փոխվում է։
